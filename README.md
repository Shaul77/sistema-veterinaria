# Sistema-Veterinaria - Backend


Proyecto desarrollado en **Python** y **Django** para la digitalización y gestión integral de atención veterinaria. Este repositorio contiene la base técnica inicial y funcional evaluada en la primera entrega académica: repositorio enlazado, aislamiento de dependencias, núcleo de Django, sistema de rutas, página de bienvenida y manejo controlado de errores HTTP 404.

---

## 1. Contexto del Problema y Propósito

Una clínica veterinaria requiere modernizar y centralizar la administración de sus operaciones clínicas. El sistema solventa la dispersión de antecedentes históricos, fichas de mascotas, citas médicas y validación de perfiles de usuario (veterinarios y dueños) mediante una arquitectura backend segura, modular y escalable construida sobre Django.

---
